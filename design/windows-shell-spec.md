# Windows Shell Specification — Stage One

- Main/background: `#0B0F17`
- Secondary surface: `#151B26`
- Border: `#293241`
- Primary text: `#F3F4F6`
- Secondary text: `#9CA3AF`
- Interactive accent: `#3730A3`
- Warning/close hover: `#C2410C`

The stage-one shell uses a 44 px custom title bar, a 12 px content-corner radius,
and a restrained drop shadow. Product components and the two demo layouts are
intentionally deferred to stage two.
