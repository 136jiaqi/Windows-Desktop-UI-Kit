# Windows Shell 规范 — 第一阶段 / Windows Shell Specification — Stage One

- 主背景 / Main background: `#0B0F17`
- 次级表面 / Secondary surface: `#151B26`
- 边框 / Border: `#293241`
- 主要文字 / Primary text: `#F3F4F6`
- 次要文字 / Secondary text: `#9CA3AF`
- 交互强调色 / Interactive accent: `#3730A3`

第一阶段外壳使用 44 px 自定义标题栏、12 px 内容圆角与克制的阴影。基础组件和两套 Demo 布局在第二阶段实现。
The stage-one shell uses a 44 px custom title bar, a 12 px content-corner radius, and a restrained drop shadow. Product components and the two demo layouts are implemented in stage two.
