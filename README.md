# Windows Desktop UI Kit

Reusable, Windows-focused shells for AI-assisted desktop EXE projects.

## v0.1.0 status

The first PySide6 shell stage is available in `shells/pyside6`: a dark, frameless
window with a reusable title bar, native system move/resize requests, and a content
insertion interface.  It deliberately contains no game or product logic.

See [the PySide6 shell README](shells/pyside6/README.md) for startup and integration
instructions.

For AI-assisted development, start with [AI_INSTRUCTIONS.md](AI_INSTRUCTIONS.md).
The reusable Agent Skill is stored in
[`agent-skills/windows-desktop-ui-kit`](agent-skills/windows-desktop-ui-kit/).
